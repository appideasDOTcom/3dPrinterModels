# Summary

A small village inn with half-timbered walls. 
I recommend to tenfold the size to achieve the scale of 1:28.
Maybe suitable for tabletop games or RPGs.



# Print Settings

Printer: K8200 Dual Extruder
Rafts: No
Supports: No
Resolution: 0.2mm per layer
Infill: 80%

Notes: 
I recommend to print the three files 'Erdgeschoss.stf', 'Obergeschoss.stf' and 'Dach.stf'.
