# Summary

This is my remix of the Hatchbox Spool Drawers.

I simple added a screw hole to to the bottom of the pegged version he created, so that the drawers can be held in place with a single M4 x 12 on the bottom, removing the need for supports for the pegged version bbraun provided.

I've also reworkd the top & bottom pieces to make stacking multiple spools easier. 

Printed on <a href="https://hooklet3d.com/promotions/odin_one.html">Odin One</a>

UPDATE 4.6.17
Made the top peg 2mm taller to help with some spools having more height.
